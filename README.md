# Minimal OS

A pared-down, music-focused OS for iPod.

Minimal OS is a customized Rockbox experience built around a simple idea:
an iPod should feel like an iPod.

It removes much of the complexity of stock Rockbox and replaces it with a
focused interface for browsing, playing, and managing music.

## Public Beta

Minimal OS is currently in public beta.

It has been extensively tested, but bugs should still be expected.
Back up your existing Rockbox installation before installing.

## Features

- Minimal music-first interface
- Artists, Albums, Songs, Playlists, and Up Next
- Multiple Now Playing layouts
- Album artwork support
- Black and white interface modes
- Simplified settings
- Automatic and manual library indexing
- Custom text input
- FLAC, MP3, AAC and other Rockbox-supported formats
- Built on Rockbox

## Supported Devices

Currently supported:

- iPod Video (5 + 5.5 Generation)
- iPod classic (6 + 7 Generation)

## Feedback

Minimal OS is still evolving.

If you find a bug or have an idea that fits the project's focus, open an
Issue or reach out to me.

The goal isn't to recreate every feature available in Rockbox. Minimal OS
is intentionally, well, minimal and will remain focused on a simple,
music-first iPod experience.

## Development

Minimal OS was developed with the assistance of AI coding tools, reviewed, and refined through repeated real-world use on supported iPod hardware.
